A little about me

I'm a backend engineer who loves building systems that just work, even when things go wrong. I spend my days working with distributed systems, event driven architectures, and payment platforms at MasterCard.

I believe great engineering is not about writing clever code. It's about writing code that your future self (and your teammates at 2 AM) can actually understand and debug.

When I'm not writing Java, I'm probably exploring how AI is reshaping the way we build software, contributing to open source, or helping engineers prep for interviews through my project Algo Arena.

Things I've built
<details> <summary><b>LedgerFlow</b> — Distributed Payment Orchestration Platform</summary> <br/> A production grade payment orchestration platform built with Java 21 and Spring Boot. It uses saga orchestration to coordinate multi step payment flows across services, with ML powered fraud detection that scores transactions in real time and LLM based risk analysis for edge cases.

Tech: Java 21, Spring Boot, Apache Kafka, PostgreSQL, Saga Pattern, ML Fraud Scoring

Why I built it: I wanted to solve the hard problem of distributed transactions in fintech. Not with a blog post, but with actual working code that handles failure gracefully.

</details> <details> <summary><b>Sentinel</b> — Real Time Anomaly Detection Engine</summary> <br/> A streaming anomaly detection system that catches unusual patterns the moment they happen, not hours later in a batch job. Uses Kafka Streams for real time processing and Welford's algorithm for online statistical analysis without storing every data point.

Tech: Java, Kafka Streams, Welford's Algorithm, PostgreSQL

Why I built it: Because by the time most alerting systems catch a problem, the damage is already done. Sentinel is built around the idea that detection should be instant.

Currently has 11 good first issues open for Hacktoberfest 2026. Contributors welcome!

</details> <details> <summary><b>Algo Arena</b> — Community DSA Interview Prep</summary> <br/> A free, community driven platform for practicing data structures and algorithms. Every week there's a new problem with progressive hints (so you don't just see the answer), company specific tags (so you know where these questions actually come up), and community solutions.

Tech: HTML, CSS, JavaScript, Vercel

Why I built it: I remember how isolating interview prep felt. Grinding problems alone at midnight. I wanted to make it feel more like a team sport.
